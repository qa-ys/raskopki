# Раскопки — прототип

Инкрементальная казуалка про археологические раскопки: копаешь пальцем, чистишь находку,
продаёшь покупателям, собираешь коллекцию.

Играть: https://qa-ys.github.io/raskopki/

Сборка самодостаточная — один HTML-файл без сборки и зависимостей. Прогресс хранится
в localStorage браузера. Чтобы начать заново, очистите данные сайта.
