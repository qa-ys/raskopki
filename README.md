# Раскопки — прототип

Инкрементальная казуалка про археологические раскопки: копаешь пальцем, чистишь находку,
продаёшь покупателям, собираешь коллекцию.

- Текущая версия (V4): https://qa-ys.github.io/raskopki/
- Предыдущая версия (V3): https://qa-ys.github.io/raskopki/v3/

V4 добавляет очередь покупателей без таймера, прокачку лавки и репутацию, разбор цены
по множителям, карту вкладками, мусорку и оффлайн-работу бригады.

Сборка самодостаточная — один HTML-файл без сборки и зависимостей. Прогресс хранится
в localStorage браузера, у V3 и V4 он раздельный. Чтобы начать заново, есть кнопка
сброса на вкладке КАРТА · МЕСТА.
